Privacy Policy

Last Updated: October 2026 • Effective Immediately

1. Our Core Philosophy: Zero Telemetry

At Pexoris (pexoris.com), your privacy is not just a policy—it is the foundational engineering principle of our software ecosystem. Unlike modern commercial tools that bundle background crash reporters, analytics trackers, and telemetry services, every single utility built by Pexoris operates 100% locally and offline.

🛡️ Absolute Offline Guarantee
Our portable executables (such as PexorisFileUnlocker.exe) contain ZERO telemetry code, make ZERO outbound network connections, and never send any file names, paths, process identifiers, or machine IDs to any remote server.

2. Desktop Utilities & Local Execution

When you download and run Pexoris portable utilities on Windows 11 or Windows 10:

  • No Installation Required: Our tools run as single, standalone binaries with zero installers or setup wizards.
  • No Registry Clutter: We do not secretly inject autorun keys or persistent telemetry background daemons into your Windows Registry.
  • Zero Diagnostic Logging: The process inspection and file handle manipulation (such as Windows Restart Manager APIs) happen strictly within your local machine's RAM.
  • Complete User Control: When you delete a Pexoris executable, it is 100% completely gone from your system without leaving background services behind.

3. Website Data Collection & Cookies

When you browse pexoris.com:

  • No Invasive Tracking Cookies: We do not use third-party advertising cookies, cross-site tracking pixels, or behavioral profiling trackers.
  • Standard Server Access Logs: Like all web servers, our web hosting provider may log standard diagnostic metadata (such as IP address, user-agent, and requested file) strictly for rate-limiting, DDoS mitigation, and server security. These logs are never tied to personal identities.
  • External Download Verification: When downloading our portable zip packages, your browser downloads directly from our server or verified GitHub release tags.

4. Open Source Verification

We believe trust must be earned through transparency. The complete C# source code and project manifests of Pexoris software are publicly available under the open-source MIT license on GitHub. Any security researcher, system administrator, or enthusiast is welcome to decompile, audit, and inspect our binaries using ILSpy, dnSpy, or Wireshark to verify that zero network connections or telemetry exist.

5. Cryptographic Checksums & Anti-Virus Safety

To ensure that your download has not been tampered with or modified by third parties, we publish the official SHA-256 cryptographic hash alongside every tool release. You can always verify file integrity using Windows PowerShell:

Get-FileHash -Algorithm SHA256 PexorisFileUnlocker.exe

6. Contact & Questions

If you have any questions regarding this Privacy Policy or wish to report a technical inquiry, feel free to open an issue on our GitHub repository or contact our team at privacy@pexoris.com.
