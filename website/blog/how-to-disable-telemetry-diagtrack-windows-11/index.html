How to Disable Telemetry & Stop DiagTrack in Windows 11 (High CPU & Disk Usage Fix)

By Pexoris Technical Team • Updated October 2026 • 6 Min Read

Quick Answer: How to Stop Windows 11 Telemetry & DiagTrack

To permanently disable Windows 11 diagnostic data collection and eliminate DiagTrack disk spikes: (1) Open elevated Command Prompt and run sc stop DiagTrack and sc config DiagTrack start= disabled. (2) Set the telemetry policy to 0 (Security / Off) via Registry: reg add HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection /v AllowTelemetry /t REG_DWORD /d 0 /f. Why Does Windows 11 DiagTrack Consume So Much Disk and CPU?

Windows 11 and 10 come pre-configured with continuous diagnostic feedback pipelines. The primary service responsible for this is Connected User Experiences and Telemetry, known in Windows services as DiagTrack.

Behind the scenes, DiagTrack continuously collects data on:

  • Application Usage Metrics: Launch times, duration of use, crashes, and background memory allocations.
  • Keyboard and Pen Inking Diagnostics: Typing dictionary samples and handwriting vector fragments.
  • Hardware Telemetry: Connected USB devices, storage drive health, and driver compatibility profiles.

On many systems, particularly laptops and desktop workstations with standard NVMe or SATA drives, DiagTrack triggers intensive background indexing cycles. Users often open Task Manager during unexpected system stutters to find DiagTrack or Service Host: Connected User Experiences and Telemetry consuming 80% to 100% disk bandwidth.

Method 1: Manual Fix via Windows Command Prompt & Registry

If you prefer managing your system manually via command-line utilities, you can stop the background telemetry daemons and configure local policy restrictions.

Step 1: Open Elevated Command Prompt

Press Win + X and choose Terminal (Admin) or search for cmd.exe, right-click, and select Run as administrator.

Step 2: Stop and Disable Telemetry Services

Execute these commands to halt DiagTrack and WAP push routing:

:: Halt and disable DiagTrack sc stop DiagTrack sc config DiagTrack start= disabled :: Halt and disable WAP Push routing service sc stop dmwappushservice sc config dmwappushservice start= disabled

Step 3: Enforce Level 0 Diagnostic Policy via Registry

Even after disabling the service, Windows group policy defaults allow diagnostic collection. You can force the diagnostic level to 0 (Security / Off):

:: Set AllowTelemetry to 0 reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection" /v AllowTelemetry /t REG_DWORD /d 0 /f :: Suppress Windows feedback prompts and satisfaction surveys reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection" /v DoNotShowFeedbackNotifications /t REG_DWORD /d 1 /f :: Disable Advertising ID user profiling reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\AdvertisingInfo" /v DisabledByGroupPolicy /t REG_DWORD /d 1 /f

Step 4: Disable CEIP and Compatibility Appraiser Scheduled Tasks

The Customer Experience Improvement Program (CEIP) runs scheduled tasks that wake your CPU to parse installed software:

:: Disable Microsoft Compatibility Appraiser schtasks /Change /TN "\Microsoft\Windows\Application Experience\Microsoft Compatibility Appraiser" /Disable :: Disable ProgramDataUpdater schtasks /Change /TN "\Microsoft\Windows\Application Experience\ProgramDataUpdater" /Disable :: Disable CEIP Consolidator schtasks /Change /TN "\Microsoft\Windows\Customer Experience Improvement Program\Consolidator" /Disable
