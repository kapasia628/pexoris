How to Flush DNS Cache in Windows 11 & Fix DNS_PROBE_FINISHED_NXDOMAIN

Published: October 2026 • Read time: 4 min • By Pexoris Technical Team

⚡ Quick Answer

To flush your DNS cache on Windows 11, press Win + S, type cmd, run as Administrator, and enter ipconfig /flushdns. To wipe routing table conflicts and reload NetBIOS at the same time, also run netsh interface ip delete arpcache and nbtstat -R. Why Do DNS Resolution Errors Occur?

When you visit a website like github.com or connect to a gaming server, Windows queries a Domain Name System (DNS) server to convert the domain name into an IP address (e.g., 140.82.121.4). To speed up subsequent visits, Windows stores this answer in a local temporary repository known as the DNS Resolver Cache.

However, problems emerge when:

  • Server IP Migrations: A website or API moves to a new web host or Cloudflare proxy, but your Windows resolver retains the outdated IP address, triggering DNS_PROBE_FINISHED_NXDOMAIN.
  • DNS Poisoning / Corrupted Lookups: Bad DNS entries or router reconnect drops cause Windows to cache invalid negative responses.
  • Winsock Catalog Desync: VPN clients, third-party firewalls, or proxy uninstallers leave fragmented network layers that prevent TCP sockets from opening.

Method 1: Manual Native Windows Fix (CMD)

You can execute standard command-line tools built into Windows to purge the resolver cache:

# 1. Flush the Windows DNS resolver cache
ipconfig /flushdns

# 2. Release current IP configuration lease
ipconfig /release

# 3. Request a fresh IP assignment from your router
ipconfig /renew

# 4. Clear local ARP routing cache
netsh interface ip delete arpcache

If web browsers still display network socket errors, you may need to reset the entire Winsock catalog to factory defaults:

# Reset Winsock catalog (requires reboot)
netsh winsock reset
netsh int ip reset

Method 2: Flush Browser-Internal DNS (Chrome & Edge)

Even after wiping the Windows OS resolver, Chromium-based browsers maintain their own independent DNS socket cache. To wipe it:

  1. Open Chrome and navigate to: chrome://net-internals/#dns
  2. Click the Clear host cache button.
  3. Navigate to chrome://net-internals/#sockets and click Flush socket pools.
