How to Restore Windows 10 Classic Context Menu in Windows 11

By Pexoris Technical Team • Updated: October 2026 • 4 Min Read
Quick Answer (Instant Fix)

To restore the Windows 10 classic right-click context menu in Windows 11, open Command Prompt as Administrator and run:
reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
Then restart Windows Explorer. To do this automatically in 1-click and clean bloated 3rd-party shell extensions, use the free 49 KB portable utility Pexoris ContextMenuEditor.

Why Does Windows 11 Hide Context Menu Items?

In Windows 11, Microsoft replaced the traditional Win32 shell context menu with a modern XAML-based menu. While designed to look sleeker, this design choice caused two major frustrations for power users and developers:

  • The "Show More Options" Barrier: Legacy commands from tools like WinRAR, 7-Zip, Notepad++, Git, and VS Code are hidden behind a second click or the Shift + F10 keyboard shortcut.
  • Right-Click Latency: Because Windows 11 queries both modern shell handlers and legacy COM servers asynchronously, right-clicking on desktop or files often freezes File Explorer for 2 to 4 seconds.

Method 2: Manual Solution via Windows Command Prompt

If you prefer using the command line without downloading software, you can apply the official Windows shell override key directly through Command Prompt:

  1. Press Win + S, type cmd, and click Run as Administrator.
  2. Paste the following registry command and press Enter:
reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
  1. Restart Windows Explorer to reload the shell with the following command:
taskkill /f /im explorer.exe & start explorer.exe

Your desktop and File Explorer will immediately display the full, classic right-click menu on the first click!

How to Revert Back to Windows 11 Modern Menu

If you ever want to revert back to the default Windows 11 modern context menu, open Command Prompt as Administrator and delete the override key:

reg delete "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}" /f

Then restart Windows Explorer. With Pexoris ContextMenuEditor, this can also be done by simply clicking the ↺ Modern Win11 Menu preset button.
