How to Disable Windows 11 Telemetry & Tracking Permanently

By Pexoris Engineering • Updated October 2026 • 6 Min Read

Quick Answer: How to Stop Windows 11 Telemetry

To permanently stop Windows 11 telemetry, you must: (1) Set AllowTelemetry = 0 in HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection, (2) Disable the DiagTrack service via sc config DiagTrack start= disabled, (3) Turn off Bing Web Search in the Start menu via DisableWebSearch = 1, and (4) Disable scheduled telemetry tasks like Microsoft Compatibility Appraiser. Why Does Windows 11 Collect So Much Data?

Out of the box, Windows 11 operates in a high-telemetry state. Microsoft routes system activity through several interconnected pipelines:

  • Diagnostic Data Collection: Transmits memory dumps, crash stack traces, browser history from Edge, and list of installed software.
  • Connected User Experiences (DiagTrack): A persistent background Windows service that monitors user interactions and uploads batch payloads.
  • Advertising ID & Profiling: Generates a unique advertising token linked to your hardware profile so Windows Store apps can serve targeted ads.
  • Start Menu Bing Queries: Every keystroke typed into the Start menu search bar is transmitted to Bing web servers before you even press Enter.
  • Inking and Typing Personalization: Captures handwriting strokes and custom typed dictionaries to train cloud speech and language models.

Method 1: Manual Windows Registry Configuration

If you prefer editing the Windows Registry manually, follow these steps using an elevated Registry Editor (regedit.exe):

1. Disable Diagnostic Data Payload

Navigate to the following key in Registry Editor:

HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\DataCollection

Create a new DWORD (32-bit) Value named AllowTelemetry and set its value to 0.

2. Disable Start Menu Bing Keystroke Logging

Prevent the Start Menu search bar from beaming your queries across the internet:

HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\Windows Search

Create a DWORD named DisableWebSearch with value 1, and another named ConnectedSearchUseWeb with value 0.

3. Turn Off Advertising ID

Disable advertising tracking for the current user profile:

HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\AdvertisingInfo

Set the Enabled DWORD to 0.

Method 2: Disable Telemetry Services via Command Line

Open an elevated Command Prompt (Run as Administrator) and run the following commands to shut down and permanently disable the DiagTrack telemetry daemon:

net stop DiagTrack sc config DiagTrack start= disabled net stop dmwappushservice sc config dmwappushservice start= disabled

Method 3: Suppress Scheduled Telemetry Tasks

Windows runs several silent maintenance tasks that wake up your CPU to compile hardware inventories. Disable them using schtasks:

schtasks /Change /TN "Microsoft\Windows\Application Experience\Microsoft Compatibility Appraiser" /Disable schtasks /Change /TN "Microsoft\Windows\Customer Experience Improvement Program\Consolidator" /Disable schtasks /Change /TN "Microsoft\Windows\Application Experience\ProgramDataUpdater" /Disable
