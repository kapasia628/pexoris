How to Clear Standby Memory in Windows 11 & Fix Gaming Stutters

Published: October 2026 • Read time: 5 min • By Pexoris Technical Team

⚡ Quick Answer

In Windows 11, files and applications you open are automatically cached in the Standby List. When demanding games need memory, Windows can freeze for 100-300ms while converting standby pages into free RAM. To fix this, use the free 58 KB Pexoris RamTrimmer utility to trigger the native kernel NtSetSystemInformation(MemoryPurgeStandbyList) routine in 1 click, instantly freeing 2 to 6 GB of cached RAM without rebooting.

What is the Windows Standby List?

If you open Task Manager, click the Performance tab, and open Resource Monitor, you will see a color-coded memory bar. The light blue section represents Standby Memory.

Standby memory contains copies of files and programs you previously used. In theory, Windows is supposed to release this memory instantly when an active application needs it. In practice, however, heavy 3D game engines (such as Unreal Engine 5, Warzone, and Cyberpunk) allocate memory rapidly in large contiguous blocks. When the free memory pool is near zero, Windows pauses execution to purge portions of the standby list, resulting in stuttering and sudden FPS drops.

The Root Cause of In-Game Micro-Stuttering

  • Low Free RAM Ceiling: Even with 16 GB or 32 GB installed, standby cache often consumes 80%+ of available capacity.
  • Memory Allocation Latency: Reclaiming memory from the standby list on-demand forces page-table synchronization across all CPU cores.
  • Pagefile Thrashing: If standby pages take too long to clear, Windows may needlessly swap background processes into the virtual page file on your SSD.

Method 1: Manual RAMMap Purge

  3. Click the top menu item Empty > Empty Standby List.
  4. Notice the standby list drop immediately in Resource Monitor.
