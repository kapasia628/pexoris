How to Find Saved Wi-Fi Passwords in Windows 11 (CMD & 1-Click Reveal)

Published: October 2026 • Read time: 4 min • By Pexoris Technical Team

⚡ Quick Answer

To view any saved Wi-Fi password in Windows 11 without digging through control panel settings, open Command Prompt and run netsh wlan show profile name="YourSSID" key=clear. The password will be revealed under Security settings > Key Content. Why Does Windows 11 Hide Previously Saved Wi-Fi Passwords?

When you connect your laptop or desktop to a wireless network, Windows 11 automatically creates an encrypted profile containing the SSID, authentication algorithm (WPA2-Personal, WPA3, WEP), cipher suite, and the pre-shared key (PSK). These profiles are stored under:

%ProgramData%\Microsoft\Wlansvc\Profiles\Interfaces

While Windows 11 allows you to inspect the password of the currently active network inside Settings > Network & Internet > Wi-Fi > Manage known networks > View Wi-Fi security key, Microsoft provides no graphical way to see passwords for networks you aren't currently connected to or that are out of range.

Method 1: Reveal Passwords via Command Prompt (Netsh)

Windows includes a powerful native command-line utility called netsh that communicates directly with the WLAN AutoConfig service.

Step 1: Discover All Saved Network Profiles

Open Command Prompt (or Windows Terminal) and execute:

netsh wlan show profiles

This prints every Wi-Fi network profile registered on your computer under User profiles.

Step 2: Decrypt the Specific Security Key

Choose the network name you wish to inspect and run the following command, making sure to include key=clear:

netsh wlan show profile name="Home_5G_Network" key=clear

Scroll down to the Security settings section. The plain-text password is displayed on the Key Content row:

Security settings ----------------- Authentication : WPA2-Personal Cipher : CCMP Security key : Present Key Content : MySecureWifiPassword2026

Limitations of the CMD Approach:

  • One Network at a Time: You must retype the command for every single profile you want to verify.
  • Syntax Errors: SSIDs containing spaces, emojis, or punctuation require strict quotation marks.
  • No Export: If you are migrating to a new laptop, you have to manually copy-paste passwords one by one.
