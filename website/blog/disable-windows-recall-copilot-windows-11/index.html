How to Disable Windows Recall & Copilot in Windows 11 24H2 (Stop AI Screenshots)

By Pexoris Security Research Team • Published: October 2026 • 5 min read
⚡ Quick Answer (10 Seconds):

To disable Windows Recall: Open Administrator CMD and run reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsAI" /v DisableAIDataAnalysis /t REG_DWORD /d 1 /f. To disable Copilot: run reg add "HKCU\Software\Policies\Microsoft\Windows\WindowsCopilot" /v TurnOffWindowsCopilot /t REG_DWORD /d 1 /f. Or use the 53 KB Pexoris AIShield utility to disable Recall, Copilot, Bing Start search, and DiagTrack in 1 click.

With the release of Windows 11 24H2, Microsoft introduced Windows Recall: an AI-driven background feature that periodically captures unencrypted screenshots of your desktop every few seconds, performs Optical Character Recognition (OCR), and catalogs your entire digital life in an indexed database.

Whether you are typing credit card numbers, reviewing confidential work emails, or reading private documents, Windows Recall captures it all. Cybersecurity researchers have already confirmed that this SQLite database is accessible to local users and commodity malware.

What Data Does Windows 11 Recall & Copilot Collect?

  • Continuous Screen Recording: Screenshots taken every 5 seconds whenever on-screen content changes.
  • Password & Health Data: Recall does not moderate passwords, medical portals, or private chat windows from being captured.
  • Start Menu Bing Telemetry: Every character you type in your Windows Start search bar is transmitted to Bing cloud servers for advertising recommendations.
  • DiagTrack Diagnostic Profiling: Background service uploading hardware IDs and app activity to Microsoft telemetry endpoints.

Method 1: Manual Group Policy & Registry Method

If you have Windows 11 Pro or Enterprise, you can disable these components via Command Prompt:

Step 1: Disable Windows Recall Screen Capture

Open Command Prompt as Administrator and execute:

reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsAI" /v DisableAIDataAnalysis /t REG_DWORD /d 1 /f reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\Recall" /v AllowSnapshot /t REG_DWORD /d 0 /f

Step 2: Disable Microsoft Copilot UI & Taskbar

Run the following command to completely disable Copilot:

reg add "HKCU\Software\Policies\Microsoft\Windows\WindowsCopilot" /v TurnOffWindowsCopilot /t REG_DWORD /d 1 /f reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v ShowCopilotButton /t REG_DWORD /d 0 /f

Step 3: Force Start Menu Search to Local Mode (Disable Bing)

Prevent Start Menu keystrokes from leaking to Bing search:

reg add "HKCU\Software\Policies\Microsoft\Windows\Explorer" /v DisableSearchBoxSuggestions /t REG_DWORD /d 1 /f

Step 4: Restart Explorer

Apply changes immediately without rebooting:

taskkill /f /im explorer.exe & start explorer.exe
