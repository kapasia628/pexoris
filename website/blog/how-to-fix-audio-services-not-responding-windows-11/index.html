How to Fix "Audio Services Not Responding" in Windows 11 (No Sound & Stuttering Fix)

By Pexoris Research Team • Published October 15, 2026 • 6 Min Read

Quick Answer: How to Fix "Audio Services Not Responding" in Windows 11

The "Audio services not responding" red X error occurs when the Windows Audio service (Audiosrv) or Endpoint Builder (AudioEndpointBuilder) halts, or when audiodg.exe crashes due to incompatible APO audio enhancements. To fix it immediately, open an elevated Command Prompt and run: net stop Audiosrv /y & net stop AudioEndpointBuilder /y & taskkill /F /IM audiodg.exe & net start AudioEndpointBuilder & net start Audiosrv & pnputil /scan-devices. The Anatomy of the "Audio Services Not Responding" Error

You sit down at your PC, join a Microsoft Teams meeting, launch YouTube, or boot into a game, only to discover complete silence. Hovering over the speaker icon in the Windows 11 taskbar reveals a red circle with an X, displaying the dreaded error tooltip: "Audio services not responding".

Running the built-in Windows Audio Troubleshooter usually loops indefinitely or reports "Troubleshooting couldn't identify the problem". Even worse, restarting the PC may temporarily restore sound, only for it to cut out again thirty minutes later.

Understanding why this happens requires peeling back the architecture of the modern Windows Audio Engine (WASAPI) and how audio graphs interact with system services.

The 4 Technical Root Causes

  1. Endpoint Builder Service Lock (AudioEndpointBuilder): This low-level service indexes multimedia hardware and maps physical 3.5mm jacks, HDMI audio feeds, and USB DACs to MMDevices registry keys. If an external USB device disconnects ungracefully or an HDMI handshake drops, AudioEndpointBuilder deadlocks, dragging down the main audio service with it.
  2. The audiodg.exe Crash & Memory Leak: The Windows Audio Device Graph Isolation process runs in user mode to isolate audio drivers from crashing the Windows kernel. However, third-party Audio Processing Objects (APOs)—such as Realtek Nahimic, Dolby Access, Waves MaxxAudio, or Creative Sound Blaster drivers—frequently leak buffer handles or spike CPU usage to 100%, causing the audio graph to freeze.
  3. Corrupted Service Startup Configurations: Aggressive "Windows debloater" scripts or malware cleaning tools occasionally alter the startup type of Audiosrv or its dependent service RpcSs to Manual or Disabled, preventing audio drivers from initializing during Windows boot.
  4. Exclusive WASAPI Mode Deadlock: When a DAW (Digital Audio Workstation) or communications tool requests exclusive hardware access at 48,000 Hz while another application feeds 44,100 Hz shared audio, the mixing pipeline can freeze, muting all system sounds until endpoints are re-enumerated.

Method 1: Force Restart Audio Services via CMD / PowerShell

The most reliable native method to revive Windows sound without a full reboot is to restart the entire audio service tree in precise dependency order and kill any hung device graph instances.

Press Win + X, select Terminal (Admin) or Command Prompt (Run as Administrator), and paste the following sequential commands:

:: 1. Ensure startup type is set to Automatic for both core services
sc config AudioEndpointBuilder start= auto
sc config Audiosrv start= auto

:: 2. Stop dependent services gracefully
net stop Audiosrv /y
net stop AudioEndpointBuilder /y

:: 3. Terminate hung Windows Audio Device Graph Isolation processes
taskkill /F /IM audiodg.exe

:: 4. Start the Endpoint Builder first
net start AudioEndpointBuilder

:: 5. Start the main Windows Audio service
net start Audiosrv

:: 6. Trigger Plug and Play device scan to re-wake DACs
pnputil /scan-devices

Method 2: Disable Audio Enhancements (Prevent audiodg.exe Spikes)

If your audio works initially but starts crackling, stuttering, or drops out whenever CPU load increases, buggy Audio Processing Objects (APOs) are the culprit:

  1. Press Win + R, type mmsys.cpl, and press Enter to open classic Sound Control Panel.
  2. In the Playback tab, right-click your default output device (e.g., Speakers / Realtek(R) Audio) and choose Properties.
  3. Navigate to the Enhancements tab (or Advanced on Windows 11 23H2/24H2).
  4. Check the box that says Disable all sound effects or Disable all enhancements.
  5. In the Advanced tab, set Default Format to 24-bit, 48000 Hz (Studio Quality) to eliminate sample-rate conversion errors.
  6. Click Apply and OK.

Method 3: Reset Multimedia Device Permissions in Registry

If the audio service refuses to start with Error 1068: The dependency service or group failed to start, the NT AUTHORITY service accounts may have lost read/write access to the MMDevices key:

:: Add LocalService and NetworkService to local Administrators group
net localgroup Administrators /add localservice
net localgroup Administrators /add networkservice

This command restores elevation privileges to the built-in Windows accounts that host audio endpoint drivers, instantly fixing Error 1068 and Error 0x80070005 (Access Denied).
