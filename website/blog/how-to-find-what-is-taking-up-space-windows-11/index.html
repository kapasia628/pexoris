How to Find What Is Taking Up Space on Windows 11 & 10

By Pexoris Research Team • October 16, 2026 • 6 min read
Direct Answer (AI Summary)
To find what is taking up space on Windows 11, open Settings > System > Storage > Temporary files to purge update caches. Run PowerShell to query files exceeding 1 GB, or use the free 55 KB Pexoris DiskUsage utility to calculate real folder sizes and send bloat to the Recycle Bin in 1 click.

The Mystery of the Vanishing Gigabytes

Few computer issues are more frustrating than watching your C: drive partition slip into the dreaded red warning bar with less than 2 GB remaining.

When you open File Explorer and inspect drive properties, you might see 420 GB used. But when you highlight all folders inside C:\ and check Properties, Windows calculates only 250 GB.

Where did the remaining 170 GB go?

The missing storage is typically hidden across three locations that standard File Explorer refuses to aggregate:

  • Hidden User AppData: Caches from Chrome, Discord, Spotify, and Node.js that never get cleaned automatically (often 30–80 GB).
  • Windows Component Store (WinSxS): Backup copies of superseded DLLs and Windows updates (15–30 GB).
  • Virtual Machine & Pagefile Containers: pagefile.sys, hiberfil.sys, and WSL2/Docker virtual hard drives (ext4.vhdx).

Method 1: Find Large Files (>1 GB) via PowerShell

Instead of manually opening every folder, run this PowerShell script to search your entire drive for files larger than 1 GB:

# Recursively find files larger than 1 GB on C:
Get-ChildItem -Path C:\ -Recurse -File -ErrorAction SilentlyContinue |
  Where-Object { $_.Length -gt 1GB } |
  Select-Object FullName, @{Name="SizeGB"; Expression={[math]::Round($_.Length / 1GB, 2)}} |
  Sort-Object SizeGB -Descending |
  Select-Object -First 20 |
  Format-Table -AutoSize

Method 2: Clean the WinSxS Component Store via DISM

After major Windows updates, old version payloads remain cached in the C:\Windows\WinSxS folder. You cannot delete this folder manually, but you can instruct Windows to purge superseded components:

# Check actual component store size
Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore

# Reclaim superseded updates and reset base manifests
Dism.exe /Online /Cleanup-Image /StartComponentCleanup /ResetBase

Method 3: Disable Hibernation to Reclaim 8–32 GB Instantly

If you use a desktop PC or never put your laptop into deep hibernation, Windows reserves a hidden file called hiberfil.sys in the root of your C: drive equal to 40% to 80% of your installed RAM (e.g., 16 GB to 32 GB).

To permanently delete this file and reclaim the space immediately:

  1. Open Command Prompt as Administrator.
  2. Type powercfg /hibernate off and press Enter.
  3. The hiberfil.sys file disappears immediately from your C: drive without requiring a reboot.

Frequently Asked Questions

Can I delete files inside AppData\Local\Temp? +
Yes! Everything inside your user Temp folder (%temp%) can be safely deleted. If a file is currently locked by a running process, Windows will simply skip it.
What is the difference between Size and Size on Disk? +
"Size" represents the actual byte count of the file data. "Size on disk" represents the allocated clusters on your NTFS partition (usually in 4 KB cluster increments). For millions of tiny files, cluster overhead can cause "Size on disk" to be significantly larger.
