How to Free Up Disk Space in Windows 11 (Clean C: Drive & Delete System Junk)

Published: October 2026 • Read time: 5 min • By Pexoris Technical Team

⚡ Quick Answer

To safely free up 10+ GB on your Windows 11 C: drive without deleting personal files, purge the hidden Windows Update staging cache in C:\Windows\SoftwareDistribution\Download, wipe Delivery Optimization queues, and delete %LOCALAPPDATA%\CrashDumps. You can do this with native Command Prompt commands or use the lightweight, zero-telemetry 50 KB portable Pexoris DiskCleaner to scan and wipe all 10 junk categories in 1 click.

Why Does Drive C: Silently Run Out of Space in Windows 11?

Even if you avoid downloading large video files or games, Windows 11 constantly accumulates background system work files that are never automatically purged:

  • Windows Update Download Staging: Every monthly cumulative update unpacks massive CAB and MSU packages into %windir%\SoftwareDistribution\Download. After the update finishes, these files remain abandoned on disk.
  • Delivery Optimization Cache: Windows shares downloaded updates with other PCs on your LAN, keeping copies in local cache folders.
  • Application Crash Dumps: When an app or browser process crashes silently in the background, Windows writes a memory dump to %LOCALAPPDATA%\CrashDumps that often exceeds 500 MB per crash.
  • DirectX Shader Caches: Modern graphics drivers compile GPU shaders for gaming and video editing into D3DSCache and DXCache, which grow continuously without automatic rotation.

Method 1: Manual Command Line Cleanup (CMD & DISM)

For advanced administrators who prefer native tools, follow these command prompt steps:

Step 1: Clean User & System Temp Files

Open Command Prompt as Administrator and run:

del /s /f /q %temp%\*.*
del /s /f /q C:\Windows\Temp\*.*

Step 2: Safely Wipe Windows Update Download Cache

Stop the update service temporarily to unlock files, purge the download directory, and restart the service:

net stop wuauserv
rmdir /s /q C:\Windows\SoftwareDistribution\Download
mkdir C:\Windows\SoftwareDistribution\Download
net start wuauserv

Step 3: Component Store Cleanup (DISM)

Reclaim obsolete superseded update components inside the WinSxS directory:

dism.exe /online /cleanup-image /startcomponentcleanup /resetbase

Pitfalls with the Manual Command-Line Approach:

  • Locked File Errors: Background applications will block del commands, throwing repeated "Access Denied" errors.
  • DISM Takes 10+ Minutes: /startcomponentcleanup performs heavy CPU-intensive operations and cannot be interrupted.
  • Scattered Paths: You must remember half a dozen deep system paths across LocalAppData, ProgramData, and Windows directories.
