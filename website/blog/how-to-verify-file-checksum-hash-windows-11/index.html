How to Verify File Checksums & Hashes (SHA-256, MD5) on Windows 11 & 10

By Pexoris Security Team • Updated October 2026 • 6 Min Read

⚡ Quick Answer: How to Check File Hashes in Windows

To verify an SHA-256 hash natively in Windows without installing any third-party tools, open PowerShell and run: Get-FileHash -Path "C:\path\to\file.iso" -Algorithm SHA256. To compare it against a publisher's checksum, check that the output hexadecimal string matches. Why Verifying Checksums Is Critical

Whenever you download a large file—such as a Windows 11 installation ISO, Linux distribution, driver package, or cryptocurrency wallet—there is always a possibility that the file was either corrupted during transmission or maliciously altered by an attacker.

Cryptographic hash functions generate a fixed-length mathematical fingerprint from your file. Even if a single bit inside a 10-gigabyte ISO is flipped, the calculated hash value changes completely (known as the avalanche effect). If your calculated checksum matches the publisher's posted hash, you have mathematical proof that:

  • No File Corruption: The download finished completely with zero packet loss or disk writing errors.
  • No Man-in-the-Middle (MITM) Tampering: A rogue Wi-Fi proxy or ISP cache did not inject malware into the installer.
  • Mirror Authenticity: Unofficial third-party download mirrors have not packaged adware or trojans into the installer.
Warning: Never verify a downloaded file solely by its file size. Attackers can pad a malicious payload with dummy bytes to match the exact byte count of an authentic executable. Only cryptographic checksums (such as SHA-256) guarantee authentic integrity.

Method 1: Native Windows PowerShell (Get-FileHash)

Windows 10 and Windows 11 include a native PowerShell cmdlet named Get-FileHash. It supports SHA1, SHA256, SHA384, SHA512, and MD5.

Step 1: Open PowerShell

Press Win + X and select Terminal or Windows PowerShell.

Step 2: Run Get-FileHash

Type the following command, replacing the path with your actual file path:

# Compute SHA-256 hash (default algorithm)
Get-FileHash -Path "C:\Users\User\Downloads\ubuntu-24.04.iso" -Algorithm SHA256

Step 3: One-Liner Compare in PowerShell

Manually comparing 64 hexadecimal characters by eye is error-prone. You can force PowerShell to verify the match automatically by comparing it with the vendor's hash:

# Compares file hash against expected vendor hash
(Get-FileHash "C:\Downloads\setup.exe" -Algorithm SHA256).Hash -eq "5E301D227F4D45543CF71A25DB0EA85779EC46162164426BF7CFD7CF454ECF6E"

If PowerShell outputs True, the file is authentic. If it outputs False, the file is corrupted or modified.

Method 2: Command Prompt via CertUtil

If you prefer standard Command Prompt (cmd.exe) without loading the PowerShell runtime, Windows provides the built-in certutil cryptographic certificate utility:

# Command Prompt SHA-256 syntax
certutil -hashfile "C:\Downloads\installer.exe" SHA256

To check MD5 or SHA512, simply replace SHA256 with MD5 or SHA512 at the end of the command.

Frequently Asked Questions

Can a corrupted file produce an identical SHA-256 hash?

No. The mathematical probability of two different files producing the same SHA-256 digest is approximately 1 in 2256 (a number greater than the number of atoms in the observable universe). If the SHA-256 hash matches, the file is identical.
