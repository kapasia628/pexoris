How to Force Delete a Stuck Print Job in Windows 11 (When "Deleting..." Never Finishes)

By Pexoris Engineering Team • Published: October 2026 • 4 min read
⚡ Quick Solution (10 Seconds):

To clear a stuck print job: Open Administrator Command Prompt and run net stop spooler, then delete all files in C:\Windows\System32\spool\PRINTERS, and run net start spooler. Alternatively, use the free 73 KB Pexoris PrintFixer utility to perform this purge in 1-click without typing commands.

Every Windows user has experienced this frustration: you send a document to print, but the printer jams or disconnects. You open the Windows Print Queue, click Cancel, and the document sits frozen on "Deleting..." for hours. Even restarting your printer does nothing, and all subsequent print jobs are blocked in line.

Why Do Print Jobs Get Stuck in Windows 11?

When you submit a print job, Windows translates your document into two temporary files stored in the protected system directory C:\Windows\System32\spool\PRINTERS:

  • .SHD (Shadow File): Contains administrative metadata like document name, owner, and job settings.
  • .SPL (Spool File): Contains the actual raw drawing and graphical data sent to the printer.

The Windows Print Spooler service (spoolsv.exe) maintains an active file handle lock on both files. If data transmission halts midway, the service refuses to release the lock. Standard Windows dialogs will not delete locked files, leaving your queue permanently frozen.

Method 1: The Manual Windows CMD Fix

If you are comfortable using the Windows Command Prompt with elevated privileges, follow these exact steps:

Step 1: Stop the Spooler Service

Press Win + S, type cmd, right-click Command Prompt, and select Run as Administrator. Enter:

net stop spooler

Step 2: Delete Corrupted Spool Files

Once the spooler service stops, delete the locked queue files by running:

del /Q /F /S "%systemroot%\System32\spool\PRINTERS\*.*"

Step 3: Restart the Spooler Service

Now restart the service so Windows can accept new print jobs:

net start spooler

Frequently Asked Questions

Will this delete my printer settings or drivers?

No. Purging the spool queue only clears temporary print jobs waiting in memory. Your installed printer drivers, wireless connections, default settings, and paper sizes remain completely untouched.

What if my printer still shows "Offline"?

Corrupted print jobs are the #1 cause of false "Offline" statuses because the spooler stops querying the printer. Purging the queue and restarting the spooler usually forces Windows to re-detect the printer as "Ready".
