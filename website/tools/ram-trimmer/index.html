Frequently Asked Questions

Everything You Need to Know About Standby Memory

The Standby List is memory that Windows uses to hold pages that are no longer in active use by processes, but which might be needed again. For instance, if you open a large video file or video game, Windows keeps copies in standby RAM so reloading is fast. However, when a new program needs memory, Windows sometimes stutters while converting standby pages into free pages. Purging the standby list frees this memory immediately.
No! Purging the standby list never crashes running applications. Standby memory only contains data that already exists safely on disk. Windows simply drops the temporary cache pointer and makes the physical RAM immediately available for any active software.
A process's "Working Set" is the set of memory pages currently resident in physical RAM. Many desktop apps (like web browsers or game clients) retain megabytes of memory for tabs or windows you haven't viewed in hours. Emptying working sets trims those dormant pages, allowing active applications to use that RAM instead.
