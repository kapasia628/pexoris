Questions Answered

Frequently Asked Questions

Why is Windows 11 default clipboard history unsafe? +
When you turn on Windows Clipboard History (Win+V), Windows writes every single item you copy into an unencrypted database file located inside your AppData directory. If you copy a password, credit card number, or API token, it remains saved in that file on your drive indefinitely. If Microsoft Account synchronization is enabled, those credentials are also transmitted across Microsoft cloud telemetry servers.
How does Pexoris ClipboardHistory prevent data recovery? +
Pexoris ClipboardHistory holds all captured items exclusively in volatile computer memory (RAM). When you close the program, click the Wipe button, or shut down your PC, the memory cells immediately lose power, rendering forensic file recovery impossible.
Does this tool replace or interfere with Ctrl+C and Ctrl+V? +
No. It uses the native Windows Win32 API AddClipboardFormatListener which passively observes clipboard change events. Your standard Ctrl+C and Ctrl+V hotkeys continue to work normally and at full speed.
How much memory does it use? +
Even with 200 items in memory, Pexoris ClipboardHistory consumes approximately 4 MB of RAM and 0.0% background CPU. It has no Electron overhead or heavy background runtime.
