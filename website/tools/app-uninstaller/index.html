Frequently Asked Questions

What makes Force Remove different from standard uninstallation? +
Standard uninstallation invokes the setup script provided by the software developer. If that script has been deleted or is corrupted, Windows will halt with an error. Force Remove directly deletes the application's registry keys in Windows uninstall hives and wipes the install folder, completely purging the broken program.
Will using Silent Uninstall restart my PC automatically? +
No. Pexoris AppUninstaller appends /norestart flags to MSI and setup commands to prevent unexpected computer reboots while you are working.
