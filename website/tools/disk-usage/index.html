Questions Answered

Frequently Asked Questions

What typically consumes the most disk space on Windows 11? +
On most Windows PCs, the biggest unexpected space hogs are hidden within AppData\Local (browser caches, Discord/Spotify cache, Docker images), C:\Windows\Temp, Windows Update rollback caches (Windows.old), and hibernation files (hiberfil.sys).
Is it safe to delete files found in Pexoris DiskUsage? +
Yes, because Pexoris DiskUsage sends files to the Windows Recycle Bin by default instead of permanently deleting them. However, you should avoid deleting files inside C:\Windows\System32 or critical driver repositories.
Why is Pexoris DiskUsage faster than Windows Settings? +
Windows Settings relies on background UWP indexing routines that query MSI installer databases and system stores. Pexoris DiskUsage utilizes direct Win32 directory stream enumeration, calculating raw byte tallies in a single continuous pass.
Is Pexoris DiskUsage completely free? +
Yes. Pexoris DiskUsage is 100% free under the open-source MIT license, with zero ads, zero subscriptions, and zero tracking.
