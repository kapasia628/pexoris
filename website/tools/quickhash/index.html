Frequently Asked Questions

Everything you need to know about hash algorithms, checksum validation, and file integrity.

What is the difference between MD5, SHA-1, SHA-256, and SHA-512? +
MD5 (128-bit) and SHA-1 (160-bit) are older hashing algorithms now considered cryptographically broken for digital signatures, but still widely used for basic corruption checks. SHA-256 (256-bit) and SHA-512 (512-bit) are modern, highly secure cryptographic standards virtually impossible to collide. Pexoris QuickHash computes all of them simultaneously.
Why is single-pass streaming faster than PowerShell Get-FileHash? +
PowerShell's Get-FileHash only computes one algorithm per invocation. If you want MD5, SHA-1, and SHA-256 for an 8 GB file, PowerShell reads the entire 8 GB file from disk three separate times (24 GB total I/O). Pexoris QuickHash streams 64 KB memory chunks across all algorithms in a single disk read, finishing in one-third the time.
Does Pexoris QuickHash support large files like 50 GB ISOs or VHDs? +
Yes. Pexoris QuickHash uses 64-bit file stream pointers and 64 KB block streaming buffers. It handles 50+ GB files seamlessly without consuming extra system memory.
Can I check hashes on locked or in-use files? +
Yes. Pexoris QuickHash opens file streams with FileShare.ReadWrite permissions, allowing it to compute checksums even on files currently opened or being read by other applications.
Is Pexoris QuickHash completely free and portable? +
Yes. It is 100% free under the MIT License. It does not install registry keys, does not touch your AppData folder, contains 0 ads, and requires 0 network connections.
