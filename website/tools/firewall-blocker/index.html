Got Questions?

Frequently Asked Questions

Why block both Outbound and Inbound traffic for an application? +
By default, Windows Defender Firewall blocks all unsolicited Inbound connections but allows virtually all Outbound connections. This means apps can secretly phone home to telemetry servers, transmit telemetry payloads, and check for updates. Blocking both Outbound and Inbound creates complete network isolation.
Does this replace Windows Defender Firewall? +
No. Pexoris FirewallBlocker acts as a lightweight, lightning-fast frontend for Windows Defender Firewall itself. It uses the native Windows Filtering Platform (WFP) COM API. When you close the program, the rules remain permanently enforced by Windows without requiring any software to stay open in the background.
What happens when I click "Block Telemetry"? +
Pexoris locates core Windows background telemetry binaries (CompatTelRunner.exe, DeviceCensus.exe, MicrosoftEdgeUpdate.exe, and SearchApp.exe) and adds persistent outbound block rules, preventing Microsoft from gathering diagnostic usage data from your PC.
What if I move or rename the blocked .exe file? +
Windows Firewall rules match the exact absolute file path of an application. If you move or rename the executable, the existing rule will no longer match. Simply drag the new executable path into Pexoris FirewallBlocker to protect it.
Does Pexoris FirewallBlocker require an internet connection? +
Never. Pexoris tools are 100% offline, standalone portable utilities. There is zero telemetry, zero automatic analytics, and zero network calls made by the utility itself.
