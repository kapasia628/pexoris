Got Questions?

Frequently Asked Questions

Why does Windows freeze when clicking a broken shortcut? +
When Windows Explorer opens a .lnk file whose target path no longer exists, Windows launches a background heuristic resolver. It crawls mapped network shares, optical drives, and secondary disks trying to guess where the file went. This often causes the taskbar and desktop to temporarily hang for 15–30 seconds.
Why do some shortcuts turn into blank white sheets? +
A shortcut displays its custom icon by reading an embedded resource index from its target executable. If the target executable is moved, renamed, or uninstalled, the shell icon resolver fails and defaults to the generic blank document icon.
Can I scan a custom external drive or USB stick? +
Yes. Pexoris ShortcutDoctor includes an optional custom directory scanner. Simply select any external folder, USB flash drive, or network share to audit all .lnk files contained inside.
Does Pexoris ShortcutDoctor delete web links or Steam shortcuts? +
No. Shortcuts that link to URLs (http/https), Steam protocol handlers (steam://rungameid), or shell namespace folders are recognized as valid healthy links and are never flagged as broken.
Is Pexoris ShortcutDoctor completely offline? +
Yes. 100% offline and standalone. Pexoris tools contain zero telemetry, zero analytics, zero external network requests, and zero background resident processes.
