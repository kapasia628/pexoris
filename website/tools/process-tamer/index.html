Frequently Asked Questions

What happens when a background process is 'Tamed'? +
When a process is tamed, its Windows scheduling priority is lowered to Idle or BelowNormal. This tells the CPU cores: "Only execute threads for this process when no active foreground app needs the processor." The task still runs and finishes, but your mouse, keyboard, and foreground applications never stutter.
Can Pexoris ProcessTamer damage my computer or corrupt files? +
No. Changing process priority class is a standard, natively supported Win32 kernel API operation. It does not terminate tasks or corrupt data. Furthermore, critical system processes (like Explorer, DWM, and csrss) are protected by a permanent safety whitelist.
Does Pexoris ProcessTamer need to stay running to protect my PC? +
If you want continuous automated auto-throttling of background spikes, leave ProcessTamer minimized. It consumes less than 8 MB of RAM and negligible CPU. Alternatively, you can use it on demand whenever a game or program starts lagging.
Why is Pexoris ProcessTamer better than Windows Task Manager? +
Task Manager only shows you what is happening—it cannot automatically react to spikes. When an infinite loop freezes your PC, Task Manager itself often becomes sluggish and unresponsive. ProcessTamer automates priority mitigation before your system grinds to a halt.
