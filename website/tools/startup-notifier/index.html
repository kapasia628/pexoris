Questions Answered

Frequently Asked Questions

Why do apps add themselves to startup without asking? +
Many software developers configure their installers to automatically inject auto-start entries into HKCU\Software\Microsoft\Windows\CurrentVersion\Run so their application updates in the background or launches faster. Over time, having dozens of apps doing this adds 30 to 60 seconds to your Windows boot time.
Is it safe to purge items using Pexoris StartupNotifier? +
Yes. Purging an auto-start entry only removes the automatic launch trigger from Windows. It does NOT delete or uninstall the application itself. You can still open and use the program anytime from your Start Menu or Desktop.
What happens if I accidentally purge a critical startup item? +
Critical Windows system processes (like Explorer or DWM) do not use the Run registry keys to start; they run as native kernel services. The Run keys are reserved for third-party user applications.
Does Pexoris StartupNotifier need an installer? +
No. Like all Pexoris tools, StartupNotifier is a single 55 KB standalone portable executable. Simply extract and run from any folder or USB drive.
