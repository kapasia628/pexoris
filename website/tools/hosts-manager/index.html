Frequently Asked Questions

Common Questions Answered

The Windows hosts file is located inside C:\Windows\System32\drivers\etc\, a protected system directory. Standard text editors like Notepad run in non-elevated user mode and cannot write to system folders. Furthermore, many third-party tools or antivirus engines set the Read-Only file attribute. Pexoris Hosts Manager runs with elevated administrator rights, clears the Read-Only flag, and writes the changes seamlessly.
No reboot is needed! Whenever you click 'Save & Flush DNS' in Pexoris Hosts Manager, it automatically invokes the Windows native DnsFlushResolverCache API and clears the system DNS resolver cache, making your routing changes take effect in all browsers immediately.
The preset maps known diagnostic tracking, crash telemetry, and intrusive ad networks (such as telemetry.microsoft.com, doubleclick.net, etc.) to 0.0.0.0 (the non-routable null address). When any application attempts to connect to these domains, Windows instantly drops the request locally without internet transmission.
