FREQUENTLY ASKED QUESTIONS

Answers to Common Questions

Does Pexoris USBShield stop USB flash drives from working? ▼
No! You can still plug in USB flash drives, browse folders in File Explorer, copy files, and use your keyboard, mouse, and external hard drives completely normally. Pexoris USBShield only blocks automatic background execution of programs and scripts when a drive is inserted.
What happens when I click 'Write-Protect ON'? ▼
Windows sets the kernel policy StorageDevicePolicies\WriteProtect = 1. This immediately puts all USB storage devices into Read-Only mode. If anyone tries to copy files onto the drive, edit an existing file, or delete data, Windows displays a "The disk is write-protected" message.
Can ransomware infect a Write-Protected USB drive? ▼
No. When write-protection is active, the file system driver rejects all write requests at the kernel level. Ransomware cannot overwrite, encrypt, or delete any files stored on the drive.
What is the 'autorun.inf vaccine'? ▼
Historically, flash drive worms create an autorun.inf file that launches malware when double-clicked. The vaccine creates a special, un-deletable directory named autorun.inf with System and Read-Only attributes. Because a directory with that name already exists, malware cannot create a file with that name.
Can I restore the original Windows settings? ▼
Yes. Simply click the ↺ Defaults preset button in the top card. Pexoris USBShield will restore standard Windows AutoPlay settings and remove write-protection policies immediately.
