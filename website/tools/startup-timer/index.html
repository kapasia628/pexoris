Got Questions?

Frequently Asked Questions

What causes slow boot times on an NVMe SSD? +
While NVMe SSDs read system files at 3000+ MB/s, boot slowdowns are almost never caused by disk transfer speeds. Instead, they occur during the post-boot phase when 10–20 third-party background applications launch concurrently, initializing updater daemons, pinging remote cloud servers, and creating system tray icons.
What is Windows Event ID 100? +
Event ID 100 is generated by the Windows Diagnostics-Performance service after every boot. It breaks down the exact millisecond cost of kernel initialization (MainPathBootTime) and the duration required for background CPU activity to settle down below 20% (BootPostBootTime).
Does disabling an app here uninstall it? +
No. Disabling an app only prevents it from auto-starting when Windows turns on. You can still launch and use the application anytime from your Start menu or desktop shortcut.
Can I re-enable a disabled app later? +
Yes. Simply select the disabled item in Pexoris StartupTimer and click ⚡ Toggle Selected again, or re-enable it directly in Windows Task Manager.
Is Pexoris StartupTimer completely free and safe? +
Yes. 100% free and open-source under the MIT license. It contains zero ads, zero telemetry, and zero third-party bundled software.
