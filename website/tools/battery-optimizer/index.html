Got Questions?

Frequently Asked Questions

Why does my Windows 11 laptop drain battery overnight while sleeping? +
Modern Windows 11 laptops default to "Modern Standby" (S0 Low Power Idle) instead of traditional S3 deep sleep. In S0 mode, Windows keeps the network interface listening to download background updates, emails, and sync OneDrive while you sleep. BatteryOptimizer modifies the Windows power policy to strictly disconnect networking when sleeping on DC power, eliminating overnight battery vampire drain.
What is battery wear level and when should I replace my battery? +
Battery Wear Level represents permanent chemical capacity loss in your lithium-ion pack. As you charge and discharge, electrodes degrade. A wear level under 15% is normal after 1 to 2 years of use. If your wear level exceeds 35% to 40%, your laptop will run out of power dramatically faster, and replacing the physical battery pack is recommended.
Does BatteryOptimizer run permanently in my system tray? +
No. Pexoris tools adhere to a zero-resident philosophy. It makes requested power configuration updates directly into the Windows powercfg registry database and exits. It never consumes memory or CPU cycles when closed.
How does the Ultra Saver profile differ from standard Windows battery saver? +
Standard Windows battery saver only dims the screen and pauses push notifications. Pexoris Ultra Saver also enforces aggressive 5-minute screen timeouts, 10-minute system sleep on battery, and sets the maximum CPU state on DC to 75% to eliminate power-hungry processor boost spikes during basic web browsing and document editing.
Can I generate an official Windows battery report? +
Yes. Clicking "Generate Battery Report" triggers the native Windows powercfg /batteryreport command and automatically launches the resulting interactive HTML audit in your default browser.
