Frequently Asked Questions

Everything you need to know about saved Wi-Fi passwords and Pexoris WifiKeyRevealer.

Can this tool recover passwords for networks I have never connected to? +
No. Pexoris WifiKeyRevealer is a security recovery and management utility, not a wireless hacker or brute-force tool. It only recovers and displays credentials for wireless networks that your computer has previously authenticated and connected to.
Why does Windows hide saved Wi-Fi passwords? +
Windows treats network security keys as sensitive configuration items. In Windows 11, viewing a password in the Settings app requires clicking into Advanced network settings, opening Adapter properties, clicking Wireless Properties, and checking 'Show characters'—which often prompts for a Windows Hello PIN. Pexoris WifiKeyRevealer eliminates all this friction by displaying all your saved keys in a single clean table.
Are my passwords sent to any external server? +
Never. Pexoris WifiKeyRevealer is a completely offline, zero-telemetry Win32 application. It contains zero internet communication capabilities, zero analytic SDKs, and zero background services. All processing happens 100% locally in your PC's memory.
Which Windows operating systems are supported? +
Pexoris WifiKeyRevealer supports Windows 11 (24H2, 23H2, 22H2), Windows 10, Windows 8.1, and Windows 7 SP1 across both 32-bit and 64-bit systems.
