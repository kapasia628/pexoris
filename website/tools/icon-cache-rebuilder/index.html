Got Questions?

Frequently Asked Questions

Everything you need to know about Windows icon cache corruption and Pexoris IconCacheRebuilder.

Why did my desktop shortcuts turn into blank white sheets? +
Windows stores pre-rendered icons in IconCache.db and iconcache_*.db to avoid reading every EXE each time the desktop loads. When these cache databases become corrupted due to hard shutdowns, driver crashes, or Windows updates, Windows fails to find the icon and displays a generic blank white document sheet instead.
Why does restarting my computer not fix the white icons? +
When Windows restarts, it simply reloads the existing corrupted IconCache.db from your disk! The corrupted file remains until it is explicitly deleted while the Windows Explorer process is stopped.
Will rebuilding the icon cache delete any personal files? +
No! It is 100% safe. Rebuilding the icon cache only deletes temporary database caches. Your shortcuts, apps, desktop layout, documents, and personal files are completely unaffected. Windows immediately rebuilds fresh copies of the icons.
Why do my desktop icons flash black or disappear briefly during rebuild? +
Because Windows Explorer (the desktop taskbar and shell) is briefly halted for less than a second to release the file handle lock on the cache databases. As soon as the databases are deleted, Explorer restarts automatically and reloads all icons cleanly.
