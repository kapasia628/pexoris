How does Pexoris DuplicateFinder prevent false positive file deletions? +

It uses a strict 3-tier algorithm: first clustering files by exact byte size, then checking the first 4KB binary header, and finally calculating a full SHA-256 cryptographic hash across the file payload. Files are only marked as duplicates if their binary data matches byte-for-byte.

Yes! Pexoris DuplicateFinder works across all file types including 4K video files, RAW camera images, MP3 audio, PDF documents, and archives. You can use the built-in File Type filter dropdown to narrow your search to specific extensions.

Yes. The "Send deleted files to Recycle Bin" option is enabled by default. Deleted files are routed to the Windows Recycle Bin, allowing you to restore them with a right-click whenever necessary.
Does Pexoris DuplicateFinder require installation or admin privileges? +
No. It runs with standard user permissions (`asInvoker`), requires zero setup or installation, and creates zero entries in the Windows registry. It is a single 56 KB standalone executable.
