FREQUENTLY ASKED QUESTIONS

Frequently Asked Questions

Everything you need to know about port conflicts, socket termination, and Pexoris PortKiller.

Why does Windows say "Port 80 (or 3000/8080) is already in use"? ▼
This error happens because another active background process (such as a previous Node.js server, Docker instance, Apache/Nginx, or Windows service) has already bound to the specified TCP/UDP port. Under standard network protocols, two programs cannot bind to the exact same local IP socket simultaneously. Terminating the blocking PID immediately releases the binding.
Why is Port 80 locked by PID 4 (System) in Windows 11? ▼
PID 4 is the Windows Kernel itself. When Port 80 is occupied by PID 4, it is virtually always caused by the Windows HTTP.sys kernel driver hosting IIS (World Wide Web Publishing Service / W3SVC), SQL Server Reporting Services, or BranchCache. Pexoris PortKiller detects this state and includes a dedicated "Stop IIS (W3SVC)" button to cleanly stop the service and free Port 80 for Apache or XAMPP.
How do I kill a process using a port in Windows 11 without restarting? ▼
Simply open Pexoris PortKiller, type the port number into the search bar, click on the row displaying the listening process, and click the red "⚡ Kill Process & Free Port" button. The tool immediately sends a termination signal to that process tree, freeing the socket in milliseconds without needing to restart your machine.
How is Pexoris PortKiller better than running "netstat -ano"? ▼
With netstat -ano, you have to open CMD as Administrator, memorize commands, find the PID, open Task Manager or type taskkill /F /PID 1234. Pexoris PortKiller scans all sockets via native Windows IP Helper APIs in 0.05 seconds, maps PIDs to readable process names and icons, and lets you kill them in 1-click.
Is Pexoris PortKiller free and safe from malware? ▼
Yes, 100%. Pexoris PortKiller is free forever, MIT open-source, contains zero adware, zero bloatware, and zero telemetry. Every release includes its cryptographic SHA-256 hash so you can verify that the binary has not been modified.
Does Pexoris PortKiller require administrator rights? ▼
Yes. Because querying system socket ownership across all processes and terminating elevated services requires administrative privilege, Pexoris PortKiller automatically requests standard Windows UAC approval on launch to ensure it can successfully free protected ports.
