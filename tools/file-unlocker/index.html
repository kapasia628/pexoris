FREQUENTLY ASKED QUESTIONS

Frequently Asked Questions

Everything you need to know about file locking, safety, and Pexoris FileUnlocker.

Why does Windows say "The action can't be completed because the file is open in another program"? ▼
This happens because a background process (such as Windows Explorer generating thumbnails, an antivirus scanner, OneDrive/Dropbox sync, or a suspended application) holds an open handle with exclusive access flags on the file. Windows kernel safeguards prevent any file modification or deletion until that handle is released.
Does Pexoris FileUnlocker require installation or administrator rights? ▼
It requires zero installation — simply download and run. Because querying handles across different system processes and modifying locked files requires system privilege, it automatically requests standard Windows Administrator approval (UAC) to ensure it has permission to unlock system-level files.
What is the difference between "Kill Process" and "Delete on Reboot"? ▼
Kill Process & Free immediately terminates the user application holding the file so you can delete it without restarting. Delete on Reboot is designed for core system files or driver files that cannot be safely terminated while Windows is running; it registers a Windows MoveFileEx operation that erases the file at boot before any programs start.
Can I add Pexoris FileUnlocker to my Windows right-click context menu? ▼
Yes! Inside the application, simply check the box "Add 'Unlock with Pexoris' to Windows Right-Click Menu". You can now right-click any locked file or folder in Windows Explorer and click "Unlock with Pexoris" to inspect it instantly. Unchecking the box removes it cleanly.
Is this tool free and safe from viruses? ▼
Pexoris FileUnlocker is 100% free, MIT open-source, and contains zero advertising, trackers, or bundled software. Every release includes its cryptographic SHA-256 hash so you can verify that the binary has not been altered.
