How to Enable Encrypted DNS-over-HTTPS (DoH) & Block Ads in Windows 11

By Pexoris Security Team • Published: October 2026 • 5 min read
⚡ Quick Answer (10 Seconds):

To enable DoH in Windows 11: Go to Settings > Network & internet > Wi-Fi/Ethernet, click Edit on DNS server assignment, choose Manual > IPv4, enter 1.1.1.1 (Cloudflare) or 94.140.14.14 (AdGuard Ad-Block), and select Encrypted only (DNS over HTTPS). Or use the 38 KB Pexoris DoH Switcher utility to toggle encrypted DNS in 1 click.

Every time you visit a website, play an online game, or launch an app, your computer sends a domain lookup request (DNS query). By default, Windows sends these requests unencrypted over UDP port 53. This means your Internet Service Provider (ISP), Wi-Fi hotspot owners, and network snoopers can log every single website you visit, even when the site itself uses HTTPS.

What is DNS-over-HTTPS (DoH) and Why Does it Matter?

DNS-over-HTTPS (DoH) encrypts your DNS lookups by routing them through standard HTTPS traffic on port 443. To any third party inspecting your network packets, your DNS queries look identical to normal encrypted web browsing.

  • Stops ISP Surveillance: Prevents internet providers from logging your browsing habits to sell targeted advertising.
  • System-Wide Ad Blocking: When paired with privacy providers like AdGuard DNS, intrusive banner ads and malicious trackers are blocked across all browsers and desktop applications simultaneously.
  • Zero Speed Loss: Unlike VPNs which reroute all data and decrease download speeds by 20% to 50%, DoH only encrypts initial domain resolution and runs at full gigabit speed.

Method 1: Manual Configuration via Windows 11 Settings

Windows 11 includes native support for DoH, but configuring it requires navigating deep through multi-level settings:

Step 1: Open Network Adapter Properties

Press Win + I to open Settings, navigate to Network & internet, and select your active connection (Wi-Fi or Ethernet).

Step 2: Change DNS Server Assignment

Scroll down to the DNS server assignment row and click the Edit button. Change the dropdown from Automatic (DHCP) to Manual.

Step 3: Enter DNS Provider IPs

Toggle IPv4 to On. Enter the server IPs of your chosen DoH resolver:

Cloudflare (Fastest): Preferred DNS: 1.1.1.1 (Encrypted only) Alternate DNS: 1.0.0.1 (Encrypted only) AdGuard (Ad-Blocking): Preferred DNS: 94.140.14.14 (Encrypted only) Alternate DNS: 94.140.15.15 (Encrypted only)

Step 4: Set Encryption to "Encrypted only (DNS over HTTPS)"

Under DNS encryption, select Encrypted only (DNS over HTTPS). Click Save.

Frequently Asked Questions

Does enabling DoH break local network printer sharing?

No. Local network discovery (.local mDNS and NetBIOS) operates independently on local broadcast protocols. Encrypted DNS only applies to public internet domain lookups.

How can I verify that my DNS queries are truly encrypted?

You can test your encryption state by visiting Cloudflare's diagnostic page at 1.1.1.1/help or AdGuard's test page. Both will confirm whether "Using DNS-over-HTTPS" is active on your Windows system.
