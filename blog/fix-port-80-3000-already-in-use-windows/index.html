Fix: Port 80 & 3000 Already in Use by PID 4 in Windows 11 (XAMPP / Docker / Node)

By Pexoris Developer Tools Team • Published: October 2026 • 5 min read
⚡ Quick Answer (10 Seconds):

To kill a blocked port: Open Administrator CMD and run netstat -ano | findstr :80 to find the PID. If owned by an app, run taskkill /PID [PID] /F. If owned by PID 4 (System), run net stop http and disable IIS in services.msc. Or use the 78 KB Pexoris PortKiller utility to identify the blocking process and free the port in 1 click.

Whether you are starting Apache in XAMPP, running a Node.js / Next.js / Vite server on port 3000, or spinning up a Docker container on port 8080, nothing halts productivity faster than this error:

Error: listen EADDRINUSE: address already in use :::3000 [Apache] Port 80 in use by "Unable to open process" with PID 4!

Why Does Windows Lock Port 80 with PID 4?

PID 4 is the Windows NT kernel process. The kernel itself doesn't serve websites, but kernel-mode network drivers run under its ID. The most common culprit is HTTP.sys, the Windows HTTP protocol stack used by:

  • World Wide Web Publishing Service (W3SVC / IIS): Pre-installed with Windows features.
  • Windows Remote Management (WinRM): Listens on port 80/5985.
  • SQL Server Reporting Services: Frequently binds to port 80 on developer laptops.
  • BranchCache: Windows corporate caching service.

Method 1: The Native Windows CMD Method

Here is how to locate the blocking process and terminate it using Windows native command-line tools:

Step 1: Locate the PID

Open Command Prompt as Administrator and run:

netstat -ano | findstr :80 netstat -ano | findstr :3000

Look at the last column on the right. That number is the Process ID (PID) holding the socket open.

Step 2: Terminate the Process (If PID != 4)

If the PID belongs to an orphaned Node.js, Python, or Java process, kill it forcefully:

taskkill /PID [Your_PID] /F

Step 3: Handle PID 4 (HTTP.sys / IIS)

If the PID is 4, you cannot run taskkill on the kernel. Instead, disable the services reserving HTTP:

net stop http sc config http start= demand
